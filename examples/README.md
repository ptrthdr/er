# WYŁĄCZNIE PRZYKŁADY

Ten katalog służy do pokazania sposobu integracji i przykładowych rozwiązań.
Nie jest częścią funkcjonalną aplikacji CodeLobby i nie przechowuje jej rzeczywistych zadań.

- `integration/` - przykładowe żądania runnera. Są także fixture testów kontraktu.
- `palindrome/` - przykładowe rozwiązania do porównania algorytmów.

W pełnym lokalnym workspace mogą dodatkowo występować `demo-frontend/`,
`team-backend/` i `execution-demo/`. To demonstratory, które nie należą do
opublikowanej wersji integracyjnej.

Wdrożenie usługi nie wymaga tego katalogu. Repozytoryjne testy kontraktu
wymagają jednak fixture z `integration/`.
